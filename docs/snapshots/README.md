# Mind Palace Architectural Snapshots

This directory contains periodic, comprehensive written snapshots of the **Mind Palace** codebase, architecture, art direction, and world state. 

As the project evolves, each snapshot serves as an immutable historical record of what existed at that milestone, capturing:
- **World Layout & Architecture** (Rooms, doors, light sources, and floor plans)
- **Entities & Inhabitants** (Player, companions, pets, automatons)
- **Interactive Stations & Encounters** (Mechanics, dialog, modals)
- **Systems & Engines** (Audio synthesis, graphics pipelines, state persistence)
- **Art Direction & Design Standards** (Sprite scales, palettes, animations)
